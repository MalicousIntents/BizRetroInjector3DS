Ultimate Retro Manager (URM) is a homebrew library manager for the Old 3DS. Browse, tag, and organize your GB, GBC, GBA, and NDS collection — and turn your NDS titles into real Home Menu launchers.

WHAT YOU'LL NEED

  • An Old 3DS — New 3DS and 2DS haven't been validated yet
  • Luma3DS with sigpatches — the .cia build is test-keyset signed
  • NTR_Forwarder installed, to launch the NDS forwarders URM creates
  • ROMs placed under sdmc:/bmedia/<platform>/ on your SD card

GETTING STARTED

  1. Set up CFW — install Luma3DS with sigpatches if you haven't already.

  2. Install NTR_Forwarder — URM's NDS launchers call into it to run.

  3. Add your ROMs — copy them into sdmc:/bmedia/<platform>/, one folder per platform.

  4. Install URM — copy URM.3dsx to /3ds/, or install URM.cia.

  5. Browse & launch — tag or favourite what you want, and create Home Menu launchers for your NDS titles.

A note on ROMs: URM does not include, host, or link to any copyrighted game files. It only works with ROMs you provide yourself. You're responsible for only using ROMs you've legally dumped from cartridges you own. Custom firmware use is at your own risk.
